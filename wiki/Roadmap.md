# Study15 ロードマップ

## 目的

参考書や教材をスマートフォンで撮影し、内容を理解しやすい約15秒の短い解説として、繰り返し見たり聞いたりできるAndroidアプリを作る。

基本方針は、可能な限り端末内で処理する。VLM/LLM、TTS、字幕、動画合成はローカル実行を優先し、重い生成動画は必須機能にしない。

## Phase 0 — 技術成立性の確認

- Android上でローカルVLM/LLMが動作することを確認する
- 参考書ページ画像から要点を抽出できることを確認する
- 抽出内容から15秒程度のやさしい口語台本を生成できることを確認する
- 日本語TTSを完全ローカルで生成できることを確認する
- 字幕タイミングをTTS音声長から生成できることを確認する
- 静止画・字幕・音声をAndroid上で短い動画に合成できることを確認する
- モデル容量、RAM使用量、生成時間、発熱を実機で測定する

### 候補技術

- VLM / LLM: LiteRT-LM
- TTS: sherpa-onnx
- 字幕 / 動画合成: AndroidX Media3 Transformer
- 任意の生成動画: stable-diffusion.cpp + Wan系モデル

## Phase 1 — 最小縦断プロトタイプ

1. カメラまたは画像選択で教材ページを入力
2. VLMでページ内容を読み取る
3. LLMで「短く・やさしい・口語」の15秒台本へ変換
4. TTSで日本語音声を生成
5. 台本を字幕区間へ分割
6. 元画像にズーム・クロップ・強調表示を付ける
7. 音声と字幕を同期して約15秒の縦型動画として再生する

この段階では、AIによるText-to-Video生成は使わない。

## Phase 2 — 学習体験

- 生成した15秒解説を連続再生できるようにする
- 同じ解説をワンタップで繰り返し再生できるようにする
- 音声だけでも繰り返し聞けるようにする
- 1ページから複数の15秒解説へ分割できるようにする
- 「もっと簡単に」「もっと短く」へ再生成できるようにする
- 元ページのどこを説明しているか分かる表示を入れる

## Phase 3 — 品質改善

- VLMの読み取り精度を評価する
- 日本語の専門用語、数式、図表を含む教材で評価する
- LLMが元教材にない内容を追加していないか確認する
- 15秒以内に収まる台本生成を安定させる
- TTSの読み方、間、速度を調整する
- 字幕量と表示速度を調整する
- クロップ・ズーム・ハイライトの自動選択を改善する

## Phase 4 — 端末内AIの実用化

- モデル初回ダウンロードと更新管理
- モデル容量の削減
- RAM不足時の制御
- VLM/LLM/TTSを同時常駐させず、必要に応じてロード・アンロードする
- GPU/NPU利用可否に応じた推論経路を整理する
- 低性能端末で利用できる縮小構成を検討する
- 完全オフライン動作を検証する

## Phase 5 — 保存・復習

- 作成した解説を教材単位で保存する
- 履歴から再生する
- お気に入り登録
- 再生回数を記録する
- 苦手な解説を繰り返し再生しやすくする
- 必要に応じてMP4として書き出す

## Phase 6 — 任意機能: ローカル生成動画

Text-to-Videoはコア要件から分離する。

- stable-diffusion.cpp / Wan系モデルのAndroid実機評価
- モデル容量と必要RAMを計測
- 生成時間と発熱を計測
- 15秒教材用途で実用性があるか判断
- 実用性が不足する場合は採用しない

## 最初の到達目標

最初の実用判定は次の一本を端末内で完結できることとする。

`教材を撮影 → 内容理解 → 15秒台本 → 日本語音声 → 字幕 → 元教材を使った短い解説動画 → 繰り返し再生`

この縦断経路が成立してから、保存、復習、生成動画などを追加する。
